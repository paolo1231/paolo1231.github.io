## 🧪 Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/paolo1231/raymondvalencia-src.git
   cd raymondvalencia-src
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   ng serve
   ```

4. Open in your browser: `http://localhost:4200/`
